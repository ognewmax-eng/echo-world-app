# Мир истории в файле .md

Персонажей, места, историю мира и культуру можно написать в любом редакторе и загрузить в ECHO WORLD одним файлом. Можно и наоборот: сохранить весь мир истории в файл, поправить и загрузить обратно или в другую историю.

**Где:** в истории «Ещё → Мир и персонажи» → кнопка **«Файл .md»**. Там же **«Скачать шаблон»**. Этот же шаблон лежит рядом: [`world-template.md`](world-template.md).

## Как устроен файл

```markdown
## Персонажи

### Тимофей
Кратко: старый лодочник, знает всех в порту.
Роль: союзник
Внешность: сутулый, седая борода.
Тайна: знает, кто зажигает огонь на маяке.
Связи:
- Старый маяк — бывал там каждую ночь

#### Что о нём говорят
- Никогда не берёт денег с вдов.

## Культура

### Ночь огней
Раз в год жители ставят фонари на воду.
```

| Что в файле | Что это |
|---|---|
| `## Название` | Раздел |
| `### Имя` | Одна запись |
| `Поле: текст` | Поле записи. Значение может занимать несколько строк — до следующего поля или заголовка |
| `#### Заголовок` | Свой блок статьи |
| Текст сразу под `### Имя` | Первый абзац — «Кратко», остальное — текст статьи |
| `<!-- так -->` | Комментарий, при загрузке пропускается. YAML-шапка Obsidian тоже |

### Разделы

Персонажи (или Герои, Люди), Места (Локации), Силы и фракции (Силы, Фракции, Организации, Гильдии), Правила мира (Правила, Законы, Магия), Культура, История, Предметы (Артефакты). Любое другое название создаст новый раздел, например `## Корабли`.

### Поля

**У любой записи:**

| Поле | Что значит |
|---|---|
| Кратко (Описание, Суть) | Одна-две строки. Это видит ИИ |
| Группа (Тип) | Подгруппа внутри раздела |
| Теги | Через запятую |
| Другие имена (Прозвища, Псевдонимы) | Через запятую. ИИ узнаёт персонажа и под ними |
| Всегда помнить | `да` или `нет`: ИИ получает запись при каждом фрагменте |
| Учитывать при письме | `да` или `нет`: видит ли ИИ статью (Культура, История, Предметы и ваши разделы) |
| Связи (Отношения) | Строками `- Имя — как связаны`. Запись с таким именем должна быть в мире или в этом же файле |

**Только в разделе «Персонажи»** (в других разделах такая строка будет обычным текстом):

| Поле | Что значит |
|---|---|
| Роль | Протагонист, союзник, антагонист… |
| Отношение к герою (Отношение) | Кем приходится главному герою |
| Внешность | Что видно; по этому же рисуется портрет |
| Возраст | |
| Характер | |
| Чего хочет (Мотивация, Цель) | |
| Как говорит (Речь, Манера речи) | ИИ держит это в репликах |
| Прошлое (Биография, Предыстория) | |
| Тайна (Секрет, Что скрывает) | Только для вас: ИИ при письме её не видит |

### Блоки статьи

Всё под `#### Заголовок` — один блок, до следующего заголовка:

- все строки начинаются с `>` — цитата;
- все строки начинаются с `-` — список;
- иначе — текст.

Заголовки `#### Текст`, `#### Цитата` и `#### Список` означают блок без своего заголовка.

## Что произойдёт при загрузке

1. **Сначала предпросмотр.** Приложение покажет, какие записи новые, какие уже есть, какие разделы появятся и что не удалось разобрать. До нажатия «Загрузить» ничего не записывается.
2. **Запись находится по разделу и имени**, регистр не важен. Такой же персонаж в другой истории — другая запись.
3. **Файл только дополняет:**
   - заполненное поле заменяет старое;
   - пустое или отсутствующее поле ничего не меняет;
   - блок с тем же заголовком заменяется, другие блоки и картинки остаются;
   - загрузить тот же файл второй раз безопасно.
4. Записи, которые уже есть, можно не трогать: снимите галочку «Дополнить записи, которые уже есть».
5. Персонажи, места, силы и правила сразу попадают в память истории. Удалённый раньше персонаж вернётся, если он есть в файле.

## Сохранение в файл

«Сохранить мир в файл» записывает всё, что есть в мире этой истории, включая то, что ИИ нашёл в тексте сам.

- **Тайны персонажей** можно не включать — снимите галочку, если файл для других.
- **Картинки в файл не входят.** Для полной копии истории с картинками есть «Экспорт → Архив».

## Ограничения

- Один файл до 1,5 МБ и до 2000 записей.
- Строка вида `Цель: …` в начале строки внутри поля персонажа будет прочитана как новое поле. Если такой текст нужен дословно, положите его в блок `####`: там поля не распознаются.
