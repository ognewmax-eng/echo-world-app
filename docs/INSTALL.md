# Установка ECHO WORLD

Полная инструкция: от нуля до первой истории на macOS, Windows и Linux. Обычно установка занимает 10 минут и ещё 5–30 минут уходит на загрузку модели.

## Из чего всё состоит

| Что | Зачем | Откуда |
|---|---|---|
| **ECHO WORLD** | Само приложение: истории, редактор, память, доска | [Релиз](https://github.com/ognewmax-eng/echo-world-app/releases/tag/v1.0.0-beta.2) |
| **Ollama** | Бесплатная программа, которая запускает нейросеть на вашем компьютере | [ollama.com](https://ollama.com/download) |
| **Модель** | Сама нейросеть, файл на 3–8 ГБ | Скачивается кнопкой в ECHO WORLD |

Все три работают на вашем компьютере, тексты никуда не отправляются. Интернет нужен только для установки и загрузки модели.

## Подойдёт ли ваш компьютер

| Система | Минимум | Чтобы писать хорошо (модель gemma4:12b) |
|---|---|---|
| **macOS** | macOS 13, 8 ГБ памяти. Mac на Intel работает, но медленно | Apple Silicon (M1 и новее), 16 ГБ памяти |
| **Windows** | Windows 10/11, 64 бит, 8 ГБ памяти | Видеокарта NVIDIA с 12 ГБ видеопамяти (RTX 3060 12 ГБ, 4070 и выше), драйвер 550+ |
| **Linux** | x86_64, glibc 2.35+ (Ubuntu 22.04, Debian 12, Fedora 36 и новее), 8 ГБ памяти | Видеокарта NVIDIA с 12 ГБ, драйвер 550+ |

- **Место на диске:** около 5 ГБ для компактной модели и около 10 ГБ для большой.
- **Без видеокарты** всё тоже работает, но на процессоре. Фрагмент текста пишется минуту-две, а не секунды. Начните с компактной модели gemma3:4b.
- **AMD Radeon** (RX 6800 и новее, серия 7000 и 9000) Ollama тоже умеет использовать. ECHO WORLD такую карту не распознаёт и предложит компактную модель, но вы можете выбрать большую сами: кнопка «Другая модель».

Сколько памяти у вашего компьютера:
- **macOS:**  → «Об этом Mac».
- **Windows:** «Диспетчер задач» (Ctrl+Shift+Esc) → «Производительность». Там «Память» и «Графический процессор» → «Выделенная память GPU».
- **Linux:** команда `free -h`; видеопамять NVIDIA — `nvidia-smi`.

## macOS

Один файл подходит и для Apple Silicon, и для Intel: **`ECHO-WORLD_1.0.0-beta.2_macos-universal.dmg`**.

### 1. Ollama

ECHO WORLD умеет запустить Ollama сам и подскажет, если её нет. Чтобы поставить её заранее:

1. Откройте [ollama.com/download/mac](https://ollama.com/download/mac) и нажмите **Download manually**.
2. Откройте скачанный файл и перетащите **Ollama** в «Программы».
3. Запустите Ollama из «Программ». При первом запуске она может предложить установить команду `ollama` для терминала — соглашаться не обязательно.
4. В строке меню вверху появится значок ламы — Ollama работает.

### 2. ECHO WORLD

1. Откройте `.dmg` и перетащите **ECHO WORLD** в папку **Applications** («Программы»).
2. Закройте окно и извлеките диск ECHO WORLD (в Finder слева, значок ⏏).
3. Откройте ECHO WORLD из «Программ».

**Первый запуск: разрешить macOS открыть приложение.** Бета не заверена в Apple, поэтому macOS один раз спросит разрешения:

1. Появится окно «Не удалось проверить „ECHO WORLD"…» — нажмите **Готово** (не «Переместить в корзину»).
2.  → **Системные настройки** → **Конфиденциальность и безопасность**.
3. Пролистайте вниз до «Безопасность»: «ECHO WORLD заблокировано…» → **Всё равно открыть**.
4. Введите пароль от Mac или приложите Touch ID и ещё раз нажмите **Открыть**.

На macOS 13–14 можно и проще: щёлкните по ECHO WORLD в «Программах» правой кнопкой → **Открыть** → **Открыть**.

## Windows

Файл: **`ECHO-WORLD_1.0.0-beta.2_windows-x64-setup.exe`**.

### 1. Ollama

1. Откройте [ollama.com/download/windows](https://ollama.com/download/windows) и нажмите **Download manually**. Скачается `OllamaSetup.exe`.
2. Запустите его и нажмите **Install**. Права администратора не нужны.
3. Ollama запустится сама, значок ламы появится в области уведомлений справа внизу (может прятаться под стрелкой ^).

Чтобы Ollama работала на видеокарте NVIDIA, обновите драйвер до версии 550 или новее: [nvidia.com/drivers](https://www.nvidia.com/drivers) или приложение NVIDIA.

### 2. ECHO WORLD

1. Запустите `ECHO-WORLD_…_windows-x64-setup.exe`.
2. **Windows может предупредить:** «Система Windows защитила ваш компьютер». Это потому, что бета не подписана сертификатом. Нажмите **Подробнее** → **Выполнить в любом случае**.
3. Установщик спросит, куда ставить, — оставьте как есть и нажмите **Далее** → **Установить** (если окно на английском: **Next** → **Install**). Права администратора не нужны: приложение ставится для вашей учётной записи.
4. Если на компьютере нет WebView2 (на Windows 10/11 он почти всегда есть), установщик скачает его сам.
5. ECHO WORLD появится в меню «Пуск».

Антивирус тоже может насторожиться на неподписанный установщик. Если он заблокировал файл, разрешите его вручную или напишите нам — [как сообщить о проблеме](#если-что-то-не-получилось).

Дальше — [модель](#модель).

## Linux

Два варианта, выберите один:

- **`ECHO-WORLD_1.0.0-beta.2_linux-x86_64.AppImage`** — один файл, работает почти в любом дистрибутиве, установка не нужна.
- **`echo-world_1.0.0-beta.2_amd64.deb`** — пакет для Ubuntu, Debian, Mint и других дистрибутивов на основе Debian, появится в меню приложений.

### 1. Ollama

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

Скрипт ставит Ollama и запускает её как службу. Проверить:

```bash
systemctl status ollama
```

Если Ollama стоит, но служба не запущена: `sudo systemctl start ollama` или просто `ollama serve` в отдельном терминале. Для видеокарты NVIDIA нужен проприетарный драйвер 550 или новее.

### 2а. AppImage

```bash
chmod +x ECHO-WORLD_1.0.0-beta.2_linux-x86_64.AppImage
```

```bash
./ECHO-WORLD_1.0.0-beta.2_linux-x86_64.AppImage
```

Если AppImage не запускается с ошибкой про FUSE, поставьте библиотеку: на Ubuntu 22.04 — `sudo apt install libfuse2`, на Ubuntu 24.04 и новее — `sudo apt install libfuse2t64`.

### 2б. Пакет .deb

```bash
sudo apt install ./echo-world_1.0.0-beta.2_amd64.deb
```

ECHO WORLD появится в меню приложений. Нужные библиотеки (WebKitGTK) apt поставит сам.

**Если окно пустое или белое** (бывает с видеокартами NVIDIA под Wayland), запустите так:

```bash
WEBKIT_DISABLE_DMABUF_RENDERER=1 echo-world
```

Для AppImage — `WEBKIT_DISABLE_DMABUF_RENDERER=1 ./ECHO-WORLD_…AppImage`.

## Модель

### Кнопками в приложении — проще всего

На главном экране ECHO WORLD справа — карточка **«Подготовим модель»**:

1. **«Запустить Ollama».** Если Ollama не найдена, карточка покажет шаги установки и кнопку «Открыть ollama.com».
2. **«Скачать …».** Приложение предложит модель под ваш компьютер. Нажмите — пойдёт загрузка с полосой прогресса. Пока она идёт, можно придумывать мир, только не закрывайте приложение. Оборвался интернет — нажмите «Скачать» ещё раз, загрузка продолжится с того же места.
3. Когда карточка станет зелёной — **«Модель … готова к работе»** — всё готово.

### Какую модель выбрать

| Модель | Размер | Для кого | Как пишет |
|---|---|---|---|
| **gemma3:4b** | 3,3 ГБ | Mac с 8 ГБ, Mac на Intel, компьютеры без видеокарты NVIDIA | Быстро, проще, иногда сбивается |
| **gemma4:12b** | 8 ГБ | Mac на Apple Silicon с 16 ГБ+, видеокарта с 12 ГБ+ | Заметно лучше: живее, держит стиль и детали |

Модель можно сменить в любой момент в «Настройках → Модель». Истории от этого не пострадают.

### Вручную, через терминал

Если кнопка не сработала или хочется поставить модель заранее, откройте терминал («Терминал» на Mac, PowerShell на Windows) и выполните:

```bash
ollama pull gemma3:4b
```

или

```bash
ollama pull gemma4:12b
```

Потом в ECHO WORLD нажмите «Проверить снова» и выберите модель — кнопкой в карточке или в выпадающем списке вверху.

## Первая история

1. Главный экран → **«Создать первую историю»**.
2. Выберите жанр, впишите название и пару фраз о том, где всё начинается. **«Начать историю»**.
3. ИИ напишет вступление. Первый ответ после запуска — самый долгий (до минуты): модель загружается в память.
4. Появится **черновик**. «Принять в историю» — и он станет частью текста.
5. Внизу напишите, что делает ваш герой, и нажмите «Продолжить историю».

Если черновик пришёл, значит всё работает. Дальше — [руководство](GUIDE.md); оно же есть в приложении по кнопке «Руководство».

## Если что-то не получилось

| Что видно | Что сделать |
|---|---|
| «Ollama не запущена», хотя она установлена | **Mac:** откройте Ollama из «Программ». **Windows:** из меню «Пуск». **Linux:** `sudo systemctl start ollama`. Затем «Проверить снова» |
| «Ollama не установлена» после установки | Закройте и снова откройте ECHO WORLD |
| Модель не скачивается | Проверьте интернет и нажмите «Скачать» ещё раз. Если не помогает — [вручную](#вручную-через-терминал) |
| «Не хватает места на диске» | Освободите 5–10 ГБ. Модели лежат в папке `.ollama` в вашей домашней папке |
| ИИ пишет очень долго (минуты на фрагмент) | Модель тяжела для компьютера или нет подходящей видеокарты. Возьмите gemma3:4b, закройте браузер и другие тяжёлые программы |
| «Модели не хватает памяти» | Закройте тяжёлые программы и нажмите «Повторить». Не помогает — модель поменьше |
| Видеокарта NVIDIA есть, а всё медленно | Обновите драйвер до 550+, перезапустите Ollama. **Linux:** после сна иногда помогает `sudo rmmod nvidia_uvm && sudo modprobe nvidia_uvm` |
| macOS: «приложение повреждено» | Скачайте `.dmg` ещё раз и [проверьте контрольную сумму](#проверить-что-файл-не-повреждён) |
| Windows: установщик не запускается | «Подробнее» → «Выполнить в любом случае». Проверьте, не заблокировал ли его антивирус |
| Linux: пустое окно | `WEBKIT_DISABLE_DMABUF_RENDERER=1` перед запуском (см. [Linux](#linux)) |

Ничего не помогло? [Создайте issue](https://github.com/ognewmax-eng/echo-world-app/issues/new?template=bug.yml) или напишите тому, кто дал вам ссылку. В приложении «Руководство → Сообщить о проблеме → Скопировать сведения» соберёт версию, систему, модель и память — без текстов ваших историй. Под любым сообщением об ошибке есть «Подробности» → «Скопировать».

## Где хранятся истории

Только на вашем компьютере:

| Система | Папка |
|---|---|
| macOS | `~/Library/Application Support/world.echo.desktop/` |
| Windows | `%APPDATA%\world.echo.desktop\` |
| Linux | `~/.local/share/world.echo.desktop/` |

Приложение само делает копию раз в день; вручную — «Настройки → Данные». Одну историю можно сохранить в файл: в истории «Ещё → Экспорт».

## Обновление и удаление

**Обновить.** Скачайте новую версию со [страницы релизов](https://github.com/ognewmax-eng/echo-world-app/releases) и поставьте поверх старой. Истории сохранятся.
- **macOS:** перетащите в «Программы» с заменой. Разрешение из первого запуска может понадобиться снова.
- **Windows:** запустите новый установщик.
- **Linux:** замените AppImage или выполните `sudo apt install ./новый.deb`.

**Удалить ECHO WORLD.**
- **macOS:** перетащите ECHO WORLD из «Программ» в корзину.
- **Windows:** «Параметры → Приложения → ECHO WORLD → Удалить».
- **Linux:** удалите AppImage или выполните `sudo apt remove echo-world`.

Истории при этом остаются в папке выше — удалите её вручную, если они не нужны.

**Удалить Ollama и модели.**
- **macOS:** Ollama — из «Программ», модели — папка `~/.ollama`.
- **Windows:** «Параметры → Приложения → Ollama», модели — `%USERPROFILE%\.ollama`.
- **Linux:** [инструкция Ollama](https://docs.ollama.com/linux#uninstall).

## Проверить, что файл не повреждён

Контрольные суммы SHA-256 указаны на странице релиза. Сравните их с выводом команды:

- **macOS / Linux:** `shasum -a 256 имя-файла` (на Linux можно `sha256sum имя-файла`).
- **Windows** (PowerShell): `Get-FileHash .\имя-файла -Algorithm SHA256`.
